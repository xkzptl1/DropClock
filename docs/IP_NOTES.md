# IP / Project Boundary Notes

This file is an engineering boundary note, not legal advice.

## Software-Only Scope

DropClock should remain a visual software renderer.

It must not be positioned as software for controlling physical water-display hardware.

Do not add hardware-control features for:

- physical valves
- pumps
- water nozzles
- PLCs
- fountains
- water curtains

without a separate legal and engineering review.

## Branding

Use the independent project name:

DropClock

Do not brand the application as:

- Osaka Station Water Clock
- JR Water Clock
- KOEI Space Printer clone
- official replica

Avoid third-party logos.

## Motifs

Generic ideas such as:

- Sakura
- Ume
- leaves
- snow
- waves
- numbers

should be rendered using original DropClock pattern data.

Do not trace or bundle third-party motif artwork.

## Public References

Public technical and visual references may be cited in documentation.

Reference material is for understanding:

- gravity behavior
- curtain-scale density
- timing
- visual rhythm

not for copying proprietary assets.

## Patent Boundary

A relevant Japanese patent family exists around physical water-display hardware and timed physical nozzle/valve control.

DropClock should remain clearly separated:

- software pixels / rendered segments only
- no physical water
- no tank
- no physical nozzle system
- no physical valve control
- no water-hardware output

Before any future physical-water implementation, conduct a fresh patent review.

## Disclaimer for README / Release

Suggested wording:

> DropClock is an independent software-only visual simulation inspired by programmable water curtains and gravity-driven water displays. It does not control physical water-display hardware and is not affiliated with JR West, Osaka Station City, or KOEI.
